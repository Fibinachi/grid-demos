# GRID Demos — Interactive Chicago Religious-Infrastructure Map

A capability demo for [GRID](https://github.com/Fibinachi/grid-demos-v2) (Global Religious Infrastructure Database): an interactive map of religious sites across Chicago, rendered as a single self-contained HTML file.

## Viewing
Open `index.html` in a browser (4.3 MB, works offline once loaded). A hosted version will be linked here once GitHub Pages is enabled.

## What's inside
- Thousands of geocoded religious sites across the Chicago area, plotted from the GRID dataset
- Built with the same enrichment pipeline as GRID itself: cross-source corroboration, geocoding, denomination classification
- Companion build pipeline: [grid-demos-v2](https://github.com/Fibinachi/grid-demos-v2)

## Context
This demo uses Chicago/Cook County — the same geography as GRID's longitudinal benchmark project (1926 → 1951 → 1963 → 2026), tracking the same institutions across a century of sources.
