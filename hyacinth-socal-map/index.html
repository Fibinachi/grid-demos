Buddhist schools of thought in GRID: Southern California sites

What this map shows. Global view: aggregated counts only, from the staged taxonomy file (snapshot 2026-10-23). Southern California view: one marker per site in the open DOI slice, 413 active sites.

What it deliberately does NOT show. No global per-site coordinates anywhere on this page. The global Buddhist sites file is a separate commercial edition under paid 14QBD273 licence and is not released by this map. Basemap differs from the deposit copy (street tiles here, dark tiles there); the data are identical.

Label gap, in plain language. GRID classifies a site by the tradition or school it belongs to (Zen, Pure Land, Tibetan, Theravada, and so on), not by the philosophy it teaches. Yogachara and Madhyamaka are doctrines, and GRID carries no label for either. School detail in practice lives in the text columns, not the ID columns: in this slice, legacy_id is present for only 3 of 413 rows, tradition_id for 2, movement_id for 2.

Gap, stated plainly: the staged package contains no global country totals, so this map's global panel is by taxonomy ID, not by country. No country figures have been invented to fill that gap. A global country-counts panel would need a separate, approved aggregate-only query against the live database (counts only, no coordinates); it is not in this build.
